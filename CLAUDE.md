# Kapi Coast — Project Brain

## About
Kapi Coast (காபி கோஸ்ட்) is a South Indian cafe in Chennai serving authentic
filter coffee, specialty teas, Andhra snacks, cakes and pastries.
Cultural identity: Tamil + Andhra coastal heritage, vintage modern aesthetic.

## Brand Colours (always use these — never generic blues or grays)
- Background: #F9F0E0 (parchment) and #F5E6C8 (cream)
- Nav / Sidebar: #5C3A1E (dark brown)
- Headings: #3D2208 (coffee dark)
- Accent / CTA: #C8882A (gold)
- Secondary accent: #A0642A (tan)

## Design Rules
- Fonts: Playfair Display for headings, DM Sans for body
- All sections must feel warm, South Indian, cultural — never generic Western cafe
- Buttons: outlined style (white text, gold or brown border) matching existing site
- Tamil script (காபி கோஸ்ட்) must appear in logo/hero area
- Cultural motifs: kolam patterns, brass tumbler, banana leaf, coastal waves

## Tech Stack
- Next.js 14 App Router + TypeScript
- Tailwind CSS with custom kc.* colour tokens
- Framer Motion for animations
- Firebase Firestore for menu data and contact form
- Deployment: Dokploy via GitHub
